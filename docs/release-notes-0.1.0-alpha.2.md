# 0.1.0-alpha.2 — local review candidate

Aksum MessageBench tests declared information preservation between local XML message pairs.
It adds a layer beyond XML parsing and XSD validation while keeping unexamined scope visible.

This candidate supports bounded subsets of pacs.008.001.08 and pacs.002.001.10, 68 synthetic
fixture pairs, exact typed comparisons, unique-key transaction association, privacy-preserving
JSON/text/HTML/JUnit evidence, file-handoff suites and regression comparison. The native XML
profile is pinned and built from verified source archives. Runtime performs no downloads,
network access, adapter execution or payment operations.

Independent human review, hosted CI and organizational release controls remain pending.
camt.053.001.08 is excluded while its schema redistribution basis is reviewed. This is not
v0.5, v1.0, certification or an operational-safety claim. See the release gate and limitations.
Python packaging spells the version `0.1.0a2`.
