# Code of conduct

Treat contributors with respect. No harassment, threats, discrimination, disclosure of
private information or retaliation. Critique technical work without personal attacks.
Maintain accessibility for contributors with different languages and experience levels.

Report concerns privately to the appointed Aksum Labs maintainer once the project is public;
the private contact must be configured before publication. For this private review packet,
use the existing private owner/reviewer channel. Maintainers should investigate fairly,
protect confidentiality, disclose conflicts and recuse where appropriate. Responses may
include a warning, removal of content, or temporary/permanent participation restrictions.
